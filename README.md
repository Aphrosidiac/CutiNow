# CutiNow - Leave Management System
CutiNow is a full-stack Leave and Holiday application system built for CetakNow. It allows employees to apply for leave, view their history, and allows admins to manage requests and leave types.

## Tech Stack
- **Frontend:** React (Vite) + TypeScript + Tailwind CSS
- **Backend:** Node.js + Express
- **Database:** PostgreSQL (with Sequelize ORM)

## Features
- **Authentication:** JWT-based Email/Password login & registration.
- **Roles:** Employee and Admin.
- **Employee:**
  - Apply for leave (calculates working days, excludes weekends).
  - Upload supporting documents (stored locally).
  - View leave balance and history.
- **Admin:**
  - Dashboard with statistics.
  - Approve/Reject leave requests with remarks.
  - Manage Leave Types (create new types).

## Setup & Installation

### Prerequisites
- Node.js (v14+)
- PostgreSQL Database

### 1. Clone & Install
```bash
git clone <repo_url>
cd cutinow

# Install all dependencies (Root, Client, Server)
npm install
npm install --prefix client
npm install --prefix server
```

### 2. Configure Environment
Create a `.env` file in the `server/` directory:
```env
PORT=5000
DATABASE_URL=postgres://user:password@localhost:5432/cutinow
JWT_SECRET=your_super_secret_key
NODE_ENV=development
```
*Replace `user:password@localhost:5432/cutinow` with your actual PostgreSQL credentials.*

### 3. Database Setup
The application will automatically create tables on first run (`sequelize.sync`).
To seed the database with an Admin user and default Leave Types, run:
```bash
node server/seed.js
```
*Default Admin Credentials:* `admin@cetaknow.com` / `admin123`

### 4. Run Locally
To run both backend and frontend concurrently:
```bash
npm start
```
- Frontend: http://localhost:5173
- Backend: http://localhost:5000

## Deployment (Railway/Render/Vercel)

### Monolithic Deployment (Recommended for Railway/Render)
1. **Build Frontend:** The backend is configured to serve the frontend static files in production.
   ```bash
   cd client && npm run build
   ```
2. **Start Server:** Set `NODE_ENV=production`. The server will serve `client/dist`.
3. **Build Command (for hosting):**
   ```bash
   cd client && npm install && npm run build && cd ../server && npm install
   ```
4. **Start Command:** `node server/index.js`

### Environment Variables on Production
- `DATABASE_URL`: Your production Postgres URL.
- `JWT_SECRET`: A strong secret.
- `NODE_ENV`: `production`
